

# IEEE RRCE – Professional Website

A modern, responsive website for IEEE at RajaRajeswari College of Engineering (RRCE), Bengaluru.

Designed to showcase the IEEE student community, technical activities, innovation, events and opportunities for student engagement through an elegant and interactive web experience.

## ✨ Features

- Modern and responsive user interface
- Interactive 3D-style hero animations
- Mouse-responsive visual effects
- Smooth scrolling and section transitions
- Animated particle effects
- Interactive hover and card effects
- Dedicated sections for IEEE communities, events and innovation
- Responsive navigation for mobile devices
- Professional institutional design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Canvas

**No frameworks or external JavaScript libraries used.**

## 🚀 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/palankardhanya-design/RRCE-IEEE-professional-website-.git
```

2. Open the project folder:

```bash
cd RRCE-IEEE-professional-website-
```

3. Open `index.html` in your browser.

You can also use the VS Code Live Server extension if installed.
